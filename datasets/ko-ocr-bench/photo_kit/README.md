# 촬영 범주 만들기 — 스마트폰 촬영·손글씨·간판

자동 생성으로는 만들 수 없는 실제 사진 범주(약 50~60장)를 위한 안내입니다.

## 1. 스마트폰 촬영 (20장) — print_targets.pdf

1. print_targets.pdf를 A4 용지에 **실제 크기(100%)**로 인쇄합니다. 흑백 인쇄도 괜찮습니다.
2. 각 장의 점선 **위쪽 문서 부분만** 화면에 들어오게 촬영합니다. 점선 아래의 촬영 ID는 찍히지 않게 합니다.
3. 조건을 섞어 주세요. 같은 조건만 있으면 평가가 한쪽으로 치우칩니다.
   - 정면 7장, 비스듬히(15~30도) 7장, 형광등·창가 그림자가 진 상태 6장
   - 책상 위, 손에 든 상태, 구겨진 종이 등 자유롭게
4. 파일 이름을 촬영 ID로 바꿔 주세요: P01.jpg ~ P20.jpg

정답은 원본 문서의 정답을 그대로 씁니다 (targets.json의 parent).

## 2. 손글씨 (15장) — handwriting.pdf

1. handwriting.pdf의 문장 H01~H15를 **종이에 손으로 따라 씁니다**. 문장 하나에 사진 한 장입니다.
2. 글씨체는 평소대로 쓰되, 문장의 글자를 바꾸거나 빼지 않습니다. 틀리게 썼다면 새로 씁니다.
3. 가능하면 2명 이상이 나눠 쓰면 좋습니다 (글씨체 다양성).
4. 파일 이름: H01.jpg ~ H15.jpg

정답은 문장 그대로입니다.

## 3. 간판·장면 문자 (15~20장)

1. 거리의 안내판, 표지판, 공공 안내문, 메뉴판, 가게 간판 등 **한글이 들어간 장면**을 촬영합니다.
2. 다음은 찍히지 않게 해 주세요: 사람 얼굴, 자동차 번호판, 개인 연락처가 적힌 전단, 주소가 특정되는 문패
3. 글자가 너무 작거나 멀면 정답 작성이 어려우니, 글자가 사진 폭의 1/10 이상이 되게 찍습니다.
4. 파일 이름: S01.jpg ~ S20.jpg

간판 사진은 원문이 없으므로 정답을 사람이 받아 적고 두 번 검수합니다 (gt의 source: manual).

## 공통

- 원본 해상도 그대로 보내 주세요 (메신저 전송 시 압축되면 품질이 떨어집니다).
- 사진의 위치 정보(EXIF GPS)는 데이터셋에 넣기 전에 제거합니다.
